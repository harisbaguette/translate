# 바로봄

현재 여행 전 시험용입니다. 처음 보는 문구의 AI 번역에는 음식 종류·맛·조리법을 잘못 옮기는 문제가 남아 있습니다.

일본 메뉴와 제품명을 비추면 한국어 뜻을 보여 주는 Android 앱입니다.

- Android 9 이상, ARM64 기기에서 사용합니다.
- 앱을 열고 카메라를 허용한 뒤 메뉴나 제품명을 비춰 주세요.
- 궁금한 글자를 누르면 화면이 고정되어 뜻과 읽는 법을 읽을 수 있습니다.
- 작은 글자는 2×로 확대하고, 흔들리는 곳에서는 ‘결과 고정’을 누르세요.
- ‘사진’으로 메뉴 사진이나 스크린샷을 가져올 수 있습니다.
- ‘저장’을 누르면 여행 단어장에 남습니다.

기본 메뉴·제품 용어는 즉시 조회합니다. 처음 보는 표현은 기기 안의 Hy-MT2가 번역하므로 더 걸릴 수 있습니다. AI 결과에는 ‘AI 번역’이 표시됩니다. 글자가 작거나 흐리거나 손글씨이면 제대로 읽지 못할 수 있습니다.

카메라 영상과 선택한 사진은 앱이 저장하지 않습니다. 저장한 단어는 단어장에서 삭제할 수 있습니다. 인터넷 연결과 로그인이 필요하지 않습니다.

상품명만으로 전체 성분·알레르기·약의 용도를 판단하지 마세요. 음식 설명은 일반적인 조리법이며 실제 재료는 매장에 확인해야 합니다.

## 설치

`바로봄.apk`를 폰으로 옮겨 열고 해당 파일 앱의 ‘알 수 없는 앱 설치’를 허용합니다. 첫 실행에는 내장 번역 모델을 준비하므로 다운로드한 APK까지 포함해 여유 저장 공간 약 2GB가 필요합니다.

## 개발

JDK 17, Android SDK 36, NDK 28.2.13676358, CMake 3.22.1을 사용합니다.

```sh
python3 tools/prepare.py
./gradlew :app:testDebugUnitTest :app:assembleRelease :app:lintRelease
```

개인 설치용 APK는 개발용 서명입니다. 공개 스토어 배포 전에는 배포용 서명과 기기 검증이 필요합니다.
